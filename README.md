# pps-web

**Portfolio web estático desarrollado con HTML, CSS y JavaScript.**

Proyecto realizado para la asignatura de **PPS (Planificación y Administración de Sistemas)**, con el objetivo de trabajar con Git y GitHub mediante el desarrollo y mantenimiento de una página web.

---

## Descripción

`pps-web` es una plantilla de portfolio personal basada en **Cleanfolio Minimal**. Está diseñada para presentar información personal, proyectos, habilidades y datos de contacto mediante una interfaz sencilla y adaptable.

El proyecto utiliza tecnologías web básicas, sin frameworks ni dependencias de desarrollo adicionales.

## Tecnologías

| Tecnología | Uso |
| :--- | :--- |
| HTML5 | Estructura de la página |
| CSS3 | Diseño y estilos |
| JavaScript | Funcionalidad e interactividad |
| Git | Control de versiones |
| GitHub | Alojamiento y colaboración |

## Características

- **Diseño responsive:** adaptación a diferentes tamaños de pantalla.
- **Modo claro y oscuro:** cambio de apariencia con persistencia mediante `localStorage`.
- **Navegación dinámica:** menú adaptable para dispositivos móviles.
- **Sección de proyectos:** presentación de trabajos y tecnologías utilizadas.
- **Sección de habilidades:** listado de conocimientos técnicos.
- **Navegación fluida:** desplazamiento entre secciones y botón para volver al inicio.

## Instalación y ejecución

No es necesario instalar dependencias ni configurar un entorno de desarrollo específico.

**1. Clonar el repositorio**

```bash
git clone https://github.com/vmarcor2403/pps-web1.git
```

**2. Acceder al directorio**

```bash
cd pps-web
```

**3. Ejecutar el proyecto**

Se puede abrir directamente `index.html` desde el navegador.

También es posible utilizar un servidor local con Python:

```bash
python -m http.server 8000
```

Después, acceder desde el navegador a:

```text
http://localhost:8000
```
